# Notebooks de práctica

Un notebook por video, en la carpeta de su serie:

```
Notebook/
├── _plantilla.ipynb          ← base para crear notebooks nuevos (scripts/notebook.py nuevo)
└── Numpy-1D/
    └── 00-plantilla.ipynb    ← notebook del video de prueba del motor
```

- **Abrir en Colab:** botón *Open in Colab* de cada notebook, o el link de la descripción del video:
  `https://colab.research.google.com/github/ChristopherArgenis/Py_UniversoDC_YT/blob/main/Notebook/<Serie>/<archivo>.ipynb`
- Vienen **sin ejecutar**: ejecuta cada celda (Shift + Enter), intenta adivinar la salida antes, y resuelve los
  ejercicios. Las soluciones están escondidas en "Ver solución".
- Para guardar tus cambios: *Archivo → Guardar una copia en Drive*.

Reglas para crearlos: ver la sección "Notebooks" de [`CLAUDE.md`](../CLAUDE.md).
